# Project Breakpoint

A work-in-progress 3D third-person action game developed with Godot Engine.

Project Breakpoint is a personal game development project focused on designing, implementing, and integrating core gameplay systems. The project is being developed incrementally, with an emphasis on understanding game mechanics, programming principles, debugging, and software architecture.

This project is part of my learning journey toward becoming a more capable game developer.

## Project Overview

- **Genre:** Third-Person Action
- **Engine:** Godot Engine
- **Programming Language:** GDScript
- **Perspective:** 3D Third-Person
- **Project Type:** Personal Learning Project
- **Development Status:** In Progress

## Implemented Features

- [x] Initial project setup and arena
- [x] Player movement, sprinting, and jumping
- [x] Third-person camera controls
- [x] Basic melee combat with hitbox detection
- [x] Attack cooldown and duplicate-hit prevention
- [x] Reusable health component
- [x] Basic enemy AI with idle, chase, and attack behaviors
- [x] Player and enemy damage interactions
- [x] Basic game loop with win/loss conditions and restart

## Learning Objectives

During development, I aim to improve my understanding of:

- Local and global transformations in 3D environments.
- Camera positioning and collision handling with SpringArm3D.
- Reusable components and modular gameplay systems.
- Combat logic, hitbox detection, cooldowns, and health management.
- Debugging techniques and systematic problem-solving.
- Structuring and maintaining gameplay code.

The goal is not only to build a playable game, but also to understand the systems behind it and the reasoning behind their implementation.

## Future Development
